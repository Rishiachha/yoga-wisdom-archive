# Yoga Wisdom Archive

Build a complete responsive React website page called:

"Yoga Knowledge Library"

for:

"Rishi Sidhasamdhi Yoga Foundation"

================================================

CORE VISION

Create a single immersive yoga knowledge experience containing all major yoga topics.

This is NOT a course landing page.

This is NOT a blog.

This is NOT a documentation website.

The experience should feel like:

- Ancient yoga manuscript

- Luxury editorial magazine

- Cinematic documentary

- Spiritual knowledge archive

- Peaceful library of wisdom

The user should feel like they are travelling through the history, philosophy and practice of Yoga.

================================================

DESIGN DIRECTION

Avoid:

- Left documentation sidebar

- Textbook layout

- Dashboard design

- Excessive cards

- SaaS style UI

- Generic yoga website

Use:

- Large cinematic images

- Editorial layouts

- Image + text storytelling

- Wide spacing

- Elegant typography

- Slow animations

- Premium magazine feeling

================================================

6. HISTORY OF YOGA SECTION

IMPORTANT:

Use historically responsible information.

Create a cinematic history journey.

Do NOT present debated archaeological interpretations as absolute facts.

Section title:

"The Journey Of Yoga Through Time"

Create a vertical timeline with images and storytelling.

Timeline:

================================================

1. EARLY INDIC TRADITIONS / PRE-VEDIC PERIOD

Approx:

Before 1700 BCE

Description:

Archaeological discoveries from the Indus Valley Civilization show early symbols and traditions of contemplation.

The relationship between these discoveries and later Yoga traditions remains debated among historians.

Visual:

Indus Valley seals / archaeological artifacts

================================================

2. VEDIC PERIOD

1700–600 BCE

Description:

Early Sanskrit literature contains ideas related to discipline, meditation, spiritual inquiry and the concept of Yoga.

Visual:

Ancient Vedic manuscripts

================================================

3. PRE-CLASSICAL PERIOD

600–200 BCE

Description:

Yoga philosophy develops through important texts including:

- Upanishads

- Bhagavad Gita

Important ideas:

- Self-realization

- Meditation

- Karma Yoga

- Bhakti Yoga

- Jnana Yoga

Visual:

Ancient manuscripts

================================================

4. CLASSICAL PERIOD

200 BCE–500 CE

Description:

Patanjali systematized Yoga philosophy through the Yoga Sutras.

Important:

Patanjali organized existing traditions;

he did not create Yoga.

Highlight:

The Eight Limbs Of Yoga:

Yama

Niyama

Asana

Pranayama

Pratyahara

Dharana

Dhyana

Samadhi

Visual:

Ancient texts

================================================

5. POST-CLASSICAL PERIOD

500–1800 CE

Description:

Yoga traditions expanded with greater emphasis on:

- Asanas

- Pranayama

- Energy practices

- Hatha Yoga traditions

Important texts:

- Hatha Yoga Pradipika

- Gheranda Samhita

- Shiva Samhita

Visual:

Hatha Yoga manuscripts

================================================

6. MODERN PERIOD

1800–Present

Description:

Yoga spread globally through teachers and movements that introduced Indian philosophical traditions and practices worldwide.

Include:

Swami Vivekananda

Tirumalai Krishnamacharya

B.K.S Iyengar

Pattabhi Jois

Visual:

Historical photographs
